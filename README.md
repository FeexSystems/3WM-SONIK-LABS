### Platform & Desktop Core

- **Desktop Shell**: Electron 35 with context-isolated IPC (`window.sonikDesktopAPI`)
- **Platform Abstraction Layer (PAL)**: Unified runtime selector (`PlatformRegistry`) for Web Audio, ASIO, WASAPI, and CoreAudio
- **C++ WebAssembly DSP**: High-speed Wasm tape saturation (`tanh` non-linear soft clipping) & 2nd-order biquad EQ
- **C++ Native Audio Engine**: Multi-driver engine (`SonikAudioEngine`) supporting low-latency ASIO, WASAPI, and CoreAudio
- **Plugin Hosting**: Native VST3 & AU host (`Vst3PluginHost`) + Web Audio/WASM plugin rack (`PluginHostManager`)
- **Compute Acceleration**: WebGPU Compute Shaders (`WGSL`) for time-domain convolution reverb & spectral FFT
- **Lock-Free DSP**: SPSC `SharedArrayBuffer` ring buffer for zero-jitter AudioWorklet thread synchronization

### Frontend Core

- **Framework**: React 19.2 (Strict Mode, Concurrent Rendering)
- **Language**: TypeScript 5.3 (Strict Type-Checking)
- **Audio DSP Engine**: Web Audio API (custom AudioWorkletProcessor), Tone.js 15.1
- **Visuals & Graphics**: Three.js, React Three Fiber 9.7 (for immersive 3D artist environments)
- **Real-Time Collaboration**: Yjs CRDTs (`ConflictResolver`), `y-webrtc` P2P mesh live jamming with track edit locks, `y-indexeddb` offline persistence, Supabase Realtime

### 3ONIK Cognitive AI Engine

- **On-Device AI Inference**: ONNX Runtime Web WebGPU & SIMD acceleration for local chord & groove generation (`LocalInferenceEngine`)
- **Multi-Agent Deliberation**: Autonomous Council consensus coordinator (`CouncilConsensusEngine`) uniting Emar, Ricky, and Kingpin
- **Bidirectional Voice Streaming**: 16kHz PCM audio streaming bridge linking microphone to Gemini Live API (`AgentVoiceUplink`)
- **Telemetry Watchdog**: Continuous buffer underrun/xrun tracker & DSP CPU performance watchdog (`ProductionDiagnostics`)

### Backend & Cloud

- **API Server**: Express 5.2 (compression, security-hardened headers)
- **Database**: Cloud Firestore (canonical world model storage) + Firebase Realtime Database
- **Analytics & ML**: BigQuery (Music ML time-series trend forecasting, predictive audio classification)
- **Rate-Limiting**: Redis (ioredis 6.0) for sliding-window API abuse protection

## 🛠️ Local Installation & Development

### 1. Prerequisites

- Node.js >= 18
- Redis (for sliding rate-limiting and budget guard)

### 2. Install Dependencies

```bash
npm install
```

### 3. Run Development Server

```bash
npm run dev
```

### 4. Production Build (Optimized assets & Standalone Server bundling)

```bash
npm run build
```
