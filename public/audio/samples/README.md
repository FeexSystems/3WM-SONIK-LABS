# Audio Samples for Landing Page

This directory contains audio samples used in the AudioShowcase section of the landing page.

## Required Files

- `raw-beat.mp3` - Raw, unmastered audio sample
- `mastered-beat.mp3` - 3WM Mastered version of the same beat

## Audio Specifications

- Format: MP3
- Sample Rate: 44.1kHz or 48kHz
- Bit Depth: 16-bit or 24-bit
- Duration: 15-30 seconds (short demo loop)
- Content: Afrofusion/Afrobeats style beat demonstrating the mastering difference

## How to Add Samples

1. Place your audio files in this directory
2. Ensure they are named exactly as specified above
3. The AudioShowcase component will automatically load them

## Note

These files are for demonstration purposes only. Replace with actual mastered/unmastered versions of your music to showcase the 3WM mastering capabilities.
