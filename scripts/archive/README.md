# Archive Directory

This directory contains historical fix and patch scripts that were used during development.

## ⚠️ WARNING

These scripts are **archived development artifacts** and should **not** be used in current development.

## Contents

- **fix\_*.py** - Historical bug fix scripts (30+ files)
- **patch\_*.py** - Historical feature patch scripts (30+ files)
- ***.sh** - Historical shell scripts (6 files)
- **create_phase5.py** - Phase 5 implementation script
- **add_log.py** - Error logging route addition
- **revert_server.py** - Server reversion script
- **strip_vault.py** - Vault UI stripping script

## Purpose

These scripts were created during rapid development to address specific issues and implement features. They have been archived to:

1. Clean up the root directory
2. Improve project organization
3. Maintain historical context
4. Prevent accidental execution

## Status

All fixes and patches from these scripts should now be integrated into the main codebase. If you need to reference any of these scripts for historical purposes, they are preserved here.

## Recommendation

Do not execute these scripts unless you are specifically debugging a historical issue and understand the full context of what the script does.
